## R8. 引用文献の Word のリンク先が、表示文字の大文字・小文字に置き換わる

- **内容**: `linker._same_as_text`（781）は `h.rstrip("/").lower() == t.rstrip("/").lower()` と URL 全体を小文字にして比べる。一致すると
  `word_hyperlinks`（334〜339）が `href=None` にして Word のリンク先を捨て、後の `urls()` が表示文字から href を作る。URL のパスは大文字・小文字を
  区別するので、リンク先が変わる。docx の文字は変わらないが、Word で設定したリンク先が知らせなく失われる。
- **再現**: 引用文献に、表示文字 `https://example.org/Study`、リンク先 `https://example.org/study` のハイパーリンク。
  → `xlink:href="https://example.org/Study"`、fidelity 合格、知らせ 0 件。本文の同じリンクは `/study` のまま（対照）。
- **既知との関係**: なし。
- **修正の方向**: スキームとホストだけを大文字・小文字を区別せずに比べ、パス・クエリは完全一致にする（末尾の `/` と DOI の分岐は今のまま）。
