# テンプレートのスタイルと JATS 要素の対応

テンプレート: `tests/fixtures/JASME_template_20261009.docx`。対応表の実体は `src/jasme_jats/data/jasme.toml` の `[styles]`。
スタイルは「名前」で照合する（Word の内部 ID ではない）。テンプレートを元に作ったスタイル（基準スタイル）も、基準をたどって照合する。

| スタイル | 役割 | JATS |
|---|---|---|
| 題目（日） | title | `article-meta/title-group/article-title[@xml:lang="ja"]` |
| 副題（日） | subtitle | `title-group/subtitle[@xml:lang="ja"]` |
| 所属（日）/ 著者名（日） | aff_ja / author_ja | `contrib-group/contrib/name-alternatives/name[@name-style="eastern"]`, `aff-alternatives/aff[@xml:lang="ja"]` |
| 題目（英）/ 副題（英） | title_en / subtitle_en | `title-group/trans-title-group[@xml:lang="en"]/trans-title`, `trans-subtitle` |
| 著者名（英）/ 所属（英） | author_en / aff_en | `name[@name-style="western"]`, `aff[@xml:lang="en"]`（和文の著者・所属と順番で対応付け） |
| 英文要旨見出し / 英文要旨 | abstract_heading / abstract | `trans-abstract[@xml:lang="en"]/title`, `p`（英文の論文では `abstract[@xml:lang="en"]`） |
| 章見出し / 節見出し / 項見出し | sec1 / sec2 / sec3 | 入れ子の `sec/title` |
| 本文（Body Text） | p | `p` |
| 図キャプション | fig_caption | `fig/caption/p`（直前の画像段落と組にする。2 段落目以降は caption の中の追加の p で、出典の行の引用・URL・注番号のリンクと PDF との照合の対象になる）。番号が重なる・枝番がある（図1-1・図1-2、図2.1）ときは、その番号の参照にリンクを付けない（要確認。枝番は 1〜2 桁で直後に数字が続かないもの。「図1―2019年度の推移」は枝番にしない） |
| 表キャプション | table_caption | `table-wrap/caption/p`（直後の表と組にする。枝番・番号の重なりは図キャプションと同じ） |
| ブロック引用 | quote | `disp-quote/p`（連続する段落を 1 つにまとめる） |
| 付記見出し | notes_heading | `back/notes/title` |
| 謝辞見出し | ack_heading | `back/ack/title` |
| 注見出し | fn_heading | `back/fn-group/title`（以降の段落を 1 段落 1 件の `fn` に。番号（「1)」「(1)」「注1)」「（注1）」「［注1］」など）で始まらない段落は前の注の続き。注の番号は `fn/p` の先頭に入れる。J-STAGE は `fn/label` を表示しないため） |
| 注本文 | fn | 注の一覧の各注の段落。本文の領域に現れたときは**本文の段落**（`p`）として出し、文字から注の見出しとは推定されない（「注」だけの段落を本文の続きにしたいときの手段。下記）。ブロック引用・図表キャプション・節見出し・項見出しのスタイルを付けると別の要素（`disp-quote`・`fig`/`table-wrap`・`sec` のタイトル）になるので、この用途には使えない |
| 参考文献見出し / 参考文献 | ref_heading / ref | `back/ref-list/title`, `ref/mixed-citation` |
| 標準（Normal） | normal | 位置と内容から推定（下記） |

## 位置による扱い

- 冒頭（題目〜最初の章見出し）の「標準」スタイルの段落（誌名・装飾行など）は出力しない（レポートに全文）。
- 英文要旨の後に「資料」「付録」「附録」「Appendix」で始まる見出しの形の段落（「資料（授業プリント）」「【資料1】」「資料Ⅱ（ワークシート）」
  「付録①　調査票」「資料1-2」「資料2　児童の記述（下線は筆者。）」「資料2 iPad の画面」「Appendix 1 questionnaire」なども。
  「資料を配布した。」「資料1、2は授業の記録である。」のような「。」か「．」で終わる和文の文と、「(Appendix 1) lists ….」のような
  「.」などで終わる英文の文は除く。除いた段落もレポートの 4 章に記録する）か、章・節・項見出しのスタイルの段落があれば、そこから
  `back/app-group/app`（どちらから始めたときもレポートの 4 章に記録する。docs/DESIGN.md の 6 章の「資料」）。
  英文要旨の段落にかな・漢字が 3 割以上あれば、移さずに「要確認」として知らせる。引用文献などの後ろに置いた資料は、今の版では
  資料にせず、「要確認」として知らせる（暫定）。
- 本文の領域で、本文・標準・章見出しのスタイルの「注」だけの段落（表の注の見出しなど）は、文字から注の見出しと推定して後付けに切り替える
  （下の推定の表）。ただし、その後ろに見出しのスタイル（章・節・項見出し）の段落が、資料の見出し以外で現れたら、注の節ではなく本文の続きとして、
  その「注」の段落から見出しの前までを本文に戻す（どちらの場合も要確認 `fn_guess`）。「注本文」スタイル（役割 fn）の「注」の段落は、本文の領域では
  本文の段落になり、文字から注の見出しと推定されない。注の節にしたいときは「注見出し」スタイル、本文の続きにしたいときは「注本文」スタイルにして
  変換し直す（AI による補完で `set_role` を指定した段落も推定しない）。
- Word の脚注・文末脚注は、本文で最初に参照される順の通し番号の `back/fn-group/fn` にする（番号は「1)」。本文から参照されていない
  注は出力しない。レポートの 6 章に全文）。手で書いた注と番号が重なるときは「要確認」として知らせる。
- 表（著者表を除く）は `table-wrap/table`。セルの複数段落は `<break/>` でつなぐ。セルの段落の中の改行（Word の Shift+Enter）の位置にも `<break/>` を入れる（改行の文字も残す。0.26.0 から）。横の結合は `colspan`、縦の結合は `rowspan`。
- 別行の数式（数式と式番号だけの段落）は `disp-formula`、式番号「(1)」は `<label>`。文中の数式は `inline-formula`。数式は MathML 2.0。
- キャプションのない画像段落は `fig`（キャプションなし）。横長の小さい画像は数式画像の可能性としてレポートに挙げる。
- テキストボックス・グループ図形に入った図表（画像・表・キャプションを含むもの）は、図の本体とキャプションを組にして、
  「図の左上の直上にある本文の文章を含む段落の直後」に置く。位置を機械的に決められるのは、図の左上がアンカー段落の左上にある場合だけで、
  それ以外は AI 補完で指定する（docs/DESIGN.md の 6.1）。表で組んだ図は `fig` の中の `table-wrap`。
  画像と文字が同じ段落にあるときは、画像を図の `graphic` に入れ、段落の文字は図の直後の `p` に出す。
- 図表の中身を持たないテキストボックス（文字だけ）は、文字数・幅・画像の近さで分ける（docs/DESIGN.md の 6.2）。問題文などの囲みは
  `boxed-text`（中の段落は `p`・`list`・`disp-quote`・`disp-formula`。本文の最初の章見出しの前なら `p` で包む）。図に重ねた注記
  （「A 点」などの短い文字）は出力しない（レポートの 6 章に全文、10 章に警告。本文の文字なら AI 補完で囲みに指定できる）。どちらか
  決められないものも出力せず、冒頭と 14 章に「要確認」として出す（AI 補完で囲みか注記かを指定できる）。図表の入った図形の中の、キャプションでない文字（図の説明・出典など）は、今までどおり図の一部とみなして出力せず、冒頭と 14 章に「要確認」として出す（位置を決められない浮動配置の図形なら、AI 補完で図を組むと、指定しなかった中身は図の後ろの段落に出る。浮動配置でない〈行内・VML の〉テキストボックスでは AI 補完でも本文の段落としては出せない〈set_role で fig_caption・table_caption にすればキャプションの続きとして出る〉ので、本文の文字なら Word でテキストボックスの外に出す）。囲みは、図表を組むときに隣の要素として数えない（画像と図キャプションの間に囲みがあっても図に組む）。
- 引用文献・注・英文の部分（資料が始まる前）などの段落に結び付いた浮動配置の図形（テキストボックス・グループ図形）の中身と、
  文字だけのテキストボックスは、その領域に入れず、本文の最後に回す（図表は位置を決められない図表として AI 補完で位置を指定する。
  文字だけのテキストボックスは上の判定で分け、囲みなら本文の最後の `boxed-text`〈要確認〉、図の注記・決められないものは本文と同じく出力しない。
  docs/DESIGN.md の 6.1）。浮動配置でない（行内の）テキストボックスの図表は、今までどおりその領域の段落になる（画像は
  「XML に入らなかった画像」として出る）。資料の中の図形は資料の中に出す。
- 題目・著者名・所属・引用文献の段落の中の画像は出力しない（画像を置けない要素のため）。レポートの冒頭・9 章・14 章に
  「XML に入らなかった画像」（要対応）として出す。
- テキストボックス・グループ図形の中の段落・表では、スタイル（「英文要旨」「参考文献見出し」など）や文字（「注」「引用文献」だけの段落）が
  あっても領域（冒頭・本文・後付け・英文の部分）を切り替えない。図形の中身は、図形が結び付いている段落と同じ領域に入る
  （和文の冒頭の最後の段落（セクション区切り）に結び付いた図形は、本文に入る。本文の外の段落に結び付いた図形は、上のとおり）。題目スタイルの段落は、テキストボックスの中にあっても題目になる。

## スタイルが想定外の段落の推定（機械的な規則）

| 条件 | 推定 |
|---|---|
| 「１．…」「1. …」で始まる短い 1 行（句点なし） | 章見出し |
| 「(1) …」で始まる短い 1 行 | 節見出し |
| 「① …」で始まる短い 1 行 | 項見出し |
| 本文スタイルでも、全体が太字で上の形式 | 見出し |
| 「表N …」で始まる短い段落で、隣が表 | 表キャプション |
| 「図N …」で始まる短い段落で、隣が画像 | 図キャプション |
| テキストボックス内の「図N …」「表N …」で始まる短い段落（「図1は…」のように番号の直後がひらがな・読点・範囲の記号のものを除く） | 図・表キャプション |
| 「引用文献」「参考文献」「文献」「引用・参考文献」「謝辞」「付記」「注」「註」「注釈」「References」「Bibliography」「Notes」「Acknowledgements」など、後付けの見出しの語だけの段落（`structure.RE_REF_HEADING_TEXT` ほか）。**スタイルが本文（Body Text）・標準・章見出しのときだけ**推定する（「注本文」など、本文の役割になるほかのスタイルや、AI が役割を指定した段落は推定しない）。「注」で推定して後付けに切り替えたあと、後ろに見出しのスタイルの段落（資料の見出しを除く）が続くと本文に戻す | 後付けの見出し |

推定した箇所と、本文のスタイルでない（「標準」など）ため本文の段落として扱った段落は、すべてレポートの「機械処理による推定」に載る。AI 補完を使うと、AI がこれらを確認・修正する（`set_role`）。
