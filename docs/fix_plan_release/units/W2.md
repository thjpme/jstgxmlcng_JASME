## 7. 危ない所

黙って誤る形が新しくできないか:

- **R1 句読点の対の当て先**。句読点の対は、段落の中で前後が一致した位置の 1 文字どうしにだけ当たる（`_align` の置き換えで、両側が 1 文字）。小数点に全角の「．」を使う docx
  （「3．5」）でも、PDF が「3.5」なら全角・半角の対で「.」になり、「。」にはならない。PDF のその位置が本当に「。」のときだけ「。」になる。類の中なら向きを問わないので、
  照合が句点の位置を取り違えても句点どうしなら直り、補完の確かめも合格する（害は小さい。句点と読点・ほかの約物の取り違えは対にならない）。
  28 論文の「．」→「。」1172 文字は、和文の文の途中・文の終わり・段落の終わりだけで、数字に挟まれた位置・英字の後・URL の近く・引用文献の領域・箇条の番号の後ろ・
  数式の隣は 0 件だった（点検で機械的に確かめた）。句点どうし・読点どうしの残り 7 件（英文要旨の「。」→「.」など）は一覧を読んだだけ。
  引用文献で「.」→「。」を直すと、`refparse` の書名・誌名のタグの境（「．」「.」は見るが「。」は見ない）が変わりうる。構造の確かめ `_structure` はリンクしか比べないので
