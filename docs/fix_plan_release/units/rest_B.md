## 2. 設計

方針（所有者の決定と D-R1-01・D-R1-15・D-R1-23 に合わせる）: 構造を変えるのは、範囲が狭く、黙って誤った出力を正しい形に戻す 2 つ（(a) 3 段落以上のキャプション、(b) 番号つきの別のキャプションを飛び越えない）だけにする。
