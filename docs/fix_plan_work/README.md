## 2. 目的と原則（要点）

- このツールは、『全国数学教育学会誌 数学教育学研究』の論文の Word（docx）を、J-STAGE の全文 XML（JATS 1.1）に変換する。
  利用者（学会の編集委員）は Google Colab のノートブックから使う。`main` に入れた変更は、その時点で利用者に届く。
- 最優先の原則: XML の本文は docx の本文と 1 文字も違ってはいけない。作り方が 2 通りある（`Options.route`）。
  - ルート1「docx から作る」: docx のまま。出版版 PDF があれば照合して、違いをレポートの 13 章に載せるだけ。
  - ルート2「出版版 PDF に合わせてから作る」: 先に docx の文字を出版版 PDF に合わせて直した docx（Word の変更履歴つき）を作り
    （`pdfdocx.py`）、それを変換する。組版の文字（ページ番号・誌名の行・柱・投稿受付日）、docx にない図・表の中の文字、ほかの段落の
    文字は docx に足さない。PDF の本文にある docx の文字は消さない。**決められない違いは docx のまま残し、理由を付けて 13 章に出す。**
- 照合（`src/jasme_jats/pdfmatch.py`）は、この計画で最も難しいコード。単位 B2（0.21.0）で、全段落をまとめて PDF と対応させる照合に
  作り直した（設計の経緯は FIX_PLAN の B2 の節）。
